## 1. 判据错误（会误报）

| 规则 | 问题 | 证据 |
|---|---|---|
| `transition-property` | 同块已有标准兜底仍报 | businessview 17 条里 **12 条**是 weui 的 `-webkit-transform`，紧随其后就有 `transition: transform` |
| `calc-min-max` | fp 到达 Skyline 前已折叠乘除/嵌套 `calc()`/number 型 min→max | `calc.rs:556-573`、`parser/property_value/mod.rs:514-535` |
| `unsupported-value` | 缺 renderer 分支豁免（`.a{display:grid}` + `.a.skyline{display:flex}`） | `unsupported_value.rs:62` 丢掉 `rule` |
| `box-sizing` | 非法值分支没有 `app_content_box()` 门控；`padding-box` 两端都非法 | `box_sizing.rs:58-65`、`box_sizing.cc:26-42` |
| `shorthand-partial` | `mask … no-clip` 不是「只丢 clip」，是整条 `mask` 回滚 | fp 语法无 `no-clip`；`parser/mod.rs:1073-1075` |
| `no-pseudo`（文案） | `nth-of-type` / `::selection` 是**降级**（约束被丢、作用到更多节点），不是「不命中」 | `css_parser_impl.h:328-332` 只 `Diag` |
| `text-decoration-line`（文案） | fp **能解析** `spelling-error`/`grammar-error`；丢值发生在 C++ default → `CSSUnsetValue` | `typing.rs:1506-1511`、`text_decoration_line.cc:49-52` |
| `unsupported-api` | `createVideoContext/MapContext/LivePlayerContext` 的「nodeId 取不到」前提不成立：传入 `this` 时 `getInfoByCaller` 会返回组件 nodeId | `Utils.js:266-289` |
| `unsupported-api` | `wx.createEditorContext` **在 SDK 里不存在**（全仓 0 命中），条目描述的是不存在的 API | `appservice/index.js:985-1006` |
| `worklet-directive`（文案） | 缺 `'worklet'` 是**不注册、不执行**，不是「退回 JS 线程」 | `wx-gesture/index.ts:206-235` 只 warn 不 `addWorkletEventHandler` |
| `horizontal-scroll-enable-flex`（方向） | 判据是 WebView 侧要求，`Target` 却是 `Skyline`，`--target webview` 永不跑 | 规则注释第一句；fixture 实测 |
| `fixed-layer` | `transform: initial/unset` 被当包含块触发条件 | `fixed_layer.rs:124-127` 只排除 `none/normal` |
| `flex-direction` | 内联 `flex-direction` 与异选择器声明都不计入 | `flex_direction.rs:130-158` 只比对选择器原文 |
| `scroll-view-type` | **整条判据错误**：JS 模板把默认槽包在 `<view wx:if="{{ type === '' }}">` 里，`firstChild` 是这个 wrapper，用户子节点全在它内部渲染 | `wx-scroll-view/index.ts:60-83`；`skyline_scroll_view.dart:1645-1673` |
| `webview/text-truncation` | `overflow` 单独出现不算截断（Skyline `max_lines_` 默认 0 = 不限制），且 `hidden` 不是合法值（转换器兜底为 `visible`）→ 两端都不截断 | `text.h:352`、`text_shadow_node.cc:266-285`、`component_attribute.rs:171-175` 自己就只收 `clip|fade|ellipsis|visible|unset` |

## 2. 原语级缺陷（一次污染多条规则）

| 原语 | 缺陷 | 影响 |
|---|---|---|
| `multipleSlots` 默认槽 | 无名 `<slot/>` 存 `None`，查找用 `name.as_deref()==Some("")` 恒假 → 未写 `slot` 的子节点祖先链 Unknown | `scroll-gesture-conflict`、`scroll-view-family`、`Facts::ancestors`、migrate |
| `width_follows_content` | 缺省 `flex-direction` 当 row，Skyline 是 column；不看交叉轴 | `unsupported-value` 的 `width: fit-content` 豁免 |
| `definite_height` | `min-height: 0` 被当作确定高度；父链用词法 `Tree::parent_of` 绕过 slot 投影 | `scroll-view-height`（两处都已实测） |
| `scroll_view_auto_size` | 读了运行时不认的顶层键（`renderer_flag`），运行时就整条规则跳过 | `scroll-view-height` 在全工程静默 |
| `cascade_entries` | 硬编码 `Dialect::Skyline`，而 `clips_overflow`/`webview_truncates` 问的是 WebView | `text-overflow-ellipsis`、`webview/text-truncation` |
| `Unknown` 传播 | 命中（Yes）会吞掉 `unresolved` | 所有级联规则；`:not(.动态类)` 场景 |
| `ancestors()` | 多使用点并集当单条链用（`break`/取第一个父节点） | `scroll-gesture-conflict`、`scroll-view-family` |
