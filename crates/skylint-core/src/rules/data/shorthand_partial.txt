# 语义：简写属性本身生效，但值里属于某个不受支持子属性的那部分会被静默丢弃，其余子属性照常。
#       长写这些子属性属于 wxss_support.txt 的 [unsupported-property]（error），不在这里。
# 格式：每行 `简写属性 | 触发的 token | 被丢弃的子属性 | 说明`，`#` 起为注释（支持行尾注释）。
#   触发的 token = ident（大小写不敏感、整值匹配，逗号分隔）；
#   `length` 是伪 token，匹配任意长度 / 百分比词元（例如 text-decoration 里的 2px）。
#   与初始值相同的 token 不收录：写了等于没写，丢弃也不改变渲染（background-attachment
#   初始值 scroll、mask-origin / mask-clip 初始值 border-box）。
# 匹配：含 var( / env( / {{ / 预处理器变量的值无法静态判定，整条声明跳过。

background | fixed,local | background-attachment | 简写里的 attachment 被丢弃
background | border-box,padding-box,content-box | background-origin / background-clip | 简写里的盒关键字被丢弃
mask | padding-box,content-box | mask-origin / mask-clip | 简写里的盒关键字被丢弃
mask | no-clip | mask-clip | no-clip 被丢弃
text-decoration | length | text-decoration-thickness | 长度值被当作 thickness 丢弃
