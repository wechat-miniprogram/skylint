# scroll-view 家族组件的结构约束。
#
# 列（TAB 分隔）：子标签 | 关系 | 目标 | 级别 | help
#   关系 direct          ：直接父节点必须是目标之一（渲染树，block/wx:if/wx:for 已摊平）
#   关系 ancestor        ：最近的同名祖先必须是目标，并满足目标上的属性要求
#   关系 first-child     ：父节点是目标容器时，子标签必须是它的第一个元素子节点
#   关系 unique          ：最近的目标容器内，子标签最多出现一次（多余的不会生效）
#   关系 before:<标签>   ：目标容器内，子标签必须排在同级 <标签> 之前
#   关系 renders-first   ：子标签只渲染第一个直接子元素，多写的会被静默丢弃
#   关系 requires-attr   ：目标写属性名，子标签必须显式声明该属性
#   关系 requires-attr-unless:<attr>=<v>：子标签必须声明目标属性，但自身 <attr>=<v> 时不要求
#                        （典型：list-builder 的 child-height 只在定高模式必填）
#   关系 allowed-values  ：目标写 attr=v1|v2，子标签该属性只能取这些静态值；未声明不报
#   关系 within:<容器>   ：最近的该容器祖先下，子标签必须声明目标里的 name=value
#   目标写法            ：tag 或 tag[attr=value]，多个目标用 | 分隔
#
# 依据（每条都能指到原句）：
# - sticky-section：scroll/sticky.md「它们必须在 <scroll-view type="custom"> 模式下使用」，
#   MUST 1「必须在 type="custom" 的 scroll-view 中使用」，NEVER 1「不要在 type="list" 的 scroll-view 中使用」。
# - list-view / grid-view：scroll/list-grid-view.md「它们必须作为 <scroll-view type="custom"> 或
#   <sticky-section> 的直接子节点使用」，NEVER 1「不要在 type="list" 的 scroll-view 中使用 list-view/grid-view」。
# - nested-scroll-header / nested-scroll-body：scroll/nested-scroll.md MUST 1
#   「外层 scroll-view 必须设置 type="nested"」。
# - sticky-header 顺序与唯一性：scroll/sticky.md MUST 2「sticky-header 必须是 sticky-section 的第一个
#   子元素」（:153）、MUST 3「每个 sticky-section 只能有一个 sticky-header」（:154）。
#   只加「在 sticky-section 内时」的条件约束，挂载位置仍不约束（见下方整条撤销的记录）。
# - nested-scroll-body 唯一：scroll/nested-scroll.md MUST 4「外层只能有一个 nested-scroll-body」（:166）、
#   NEVER 2「不要有多个 nested-scroll-body」。
# - nested-scroll-header 顺序：nested-scroll.md:29「只能渲染在 nested-scroll-body 上面」、
#   NEVER 1「不要在 nested-scroll-body 下面放 nested-scroll-header」（:170）。
# - 只渲染第一个子节点：nested-scroll.md:29（header）、:38（body）。多写的会被静默丢弃，故为 warning。
# - list-builder / grid-view 必需属性：scroll/list-grid-view.md MUST 2「使用 list-builder 时必须指定
#   child-height（定高模式）」（:271）、MUST 3「网格布局必须指定 cross-axis-count」（:272）。
# - list-builder type：list-grid-view.md:155「type | string | static | 列表模式：static（定高）/ dynamic（不定高）」。
# - grid-view type：list-grid-view.md:65「type | string | aligned / masonry」。
# - 内层 scroll-view 关联容器：nested-scroll.md MUST 2「内层 scroll-view 必须设置
#   associative-container="nested-scroll-view"」（:164）、NEVER 3「不要忘记给内层 scroll-view 设置」。作用域取
#   nested-scroll-body：文档示例里内层 scroll-view 在 body 内的 swiper 下（:210-:224），而 header 内的
#   scroll-view 不参与嵌套滚动（sticky 里的横向 tab 列表就属于这种）。
# - draggable-sheet 内 scroll-view 关联容器：draggable-sheet.md:50、:342
#   「内部的 scroll-view 必须设置 associative-container="draggable-sheet"」。
#
# 文档冲突记录：skyline-overview/references/introduction/component-support.md 写
# 「list-view | 列表布局容器，作为 scroll-view type="list" 的直接子节点」，与
# scroll/list-grid-view.md（必须 custom）以及 SKILL.md MUST 4 冲突。这里按更具体、
# 且被 scroll-view.md type 表（custom 支持 list-view/grid-view/sticky-section）
# 印证的 list-grid-view.md 实现。
#
# 文档冲突记录（sticky-header 的挂载位置，整条撤销）：scroll/sticky.md NEVER 2 写「不要将
# sticky-header 放在 sticky-section 之外」，但 scroll/scroll-view.md:54 在 custom 模式的
# 「支持的子组件」里明确列出 `sticky-section` / `sticky-header`，即 sticky-header 也可以
# 作为 scroll-view 的直接子节点。生产工程 miniprogram-skit_1 的 rank.wxml 正是
# <nested-scroll-header><sticky-header> 的写法且在跑。两份文档互相冲突，按「文档没写清
# 或互相矛盾就不报」的原则，不对 sticky-header 的挂载位置做任何约束。
sticky-section	ancestor	scroll-view[type=custom]	error	把 `<sticky-section>` 放进 `<scroll-view type="custom">`，type 不能是 list/nested
list-view	direct	scroll-view[type=custom]|sticky-section	error	把 `<list-view>` 移为 `<scroll-view type="custom">` 或 `<sticky-section>` 的直接子节点
grid-view	direct	scroll-view[type=custom]|sticky-section	error	把 `<grid-view>` 移为 `<scroll-view type="custom">` 或 `<sticky-section>` 的直接子节点
nested-scroll-header	ancestor	scroll-view[type=nested]	error	把 `<nested-scroll-header>` 放在外层 `<scroll-view type="nested">` 内
nested-scroll-body	ancestor	scroll-view[type=nested]	error	把 `<nested-scroll-body>` 放在外层 `<scroll-view type="nested">` 内
sticky-header	first-child	sticky-section	error	把 `<sticky-header>` 移到 `<sticky-section>` 的第一个元素子节点位置
sticky-header	unique	sticky-section	error	一个 `<sticky-section>` 只保留一个 `<sticky-header>`
nested-scroll-body	unique	scroll-view[type=nested]	error	外层 `<scroll-view type="nested">` 只保留一个 `<nested-scroll-body>`
nested-scroll-header	before:nested-scroll-body	scroll-view[type=nested]	error	把 `<nested-scroll-header>` 移到 `<nested-scroll-body>` 之前
nested-scroll-header	renders-first	-	warning	把头部内容收进一个直接子节点（例如一个 `<view>`）
nested-scroll-body	renders-first	-	warning	把主体内容收进一个直接子节点（例如一个 `<view>`）
list-builder	requires-attr-unless:type=dynamic	child-height	error	在 `<list-builder>` 上声明列表项高度 `child-height`（定高模式必填）
grid-view	requires-attr	cross-axis-count	error	在 `<grid-view>` 上声明交叉轴元素数量 `cross-axis-count`
list-builder	allowed-values	type=static|dynamic	error	`type` 只能是 `static`（定高）或 `dynamic`（不定高）
grid-view	allowed-values	type=aligned|masonry	error	`type` 只能是 `aligned`（网格）或 `masonry`（瀑布流）
scroll-view	within:nested-scroll-body	associative-container=nested-scroll-view	error	给 `<nested-scroll-body>` 内的 `<scroll-view>` 加上 `associative-container="nested-scroll-view"`
scroll-view	within:draggable-sheet	associative-container=draggable-sheet	warning	给 `<draggable-sheet>` 内的 `<scroll-view>` 加上 `associative-container="draggable-sheet"`
