# 同步方式：只收录文档明确写「Skyline 不支持 / 仅 WebView 支持 / 取值范围」的属性取值；
#   枚举值以文档表格为准，行尾注释写 references 相对路径与行号。组件不能拆成多条规则。
# 格式：分区下每行 `组件 | 属性 | 约束 | 说明`
#   - 组件、属性一律小写；两者都可用逗号分隔写多个（共用同一约束）。
#   - `#` 起为注释（支持行尾注释）；说明为 `-` 时使用按约束生成的默认文案。
#   - [webview-only] 约束 = 逗号分隔的、只在 WebView 下生效的值；命中即报，优先级高于 [enum]。
#   - [enum]        约束 = 逗号分隔的合法值；值以 `*` 结尾表示前缀匹配（如 cubic-bezier*）。
#   - [unsupported] 约束固定为 `-`，属性出现即报；属性名以 `*` 结尾表示前缀匹配
#                   （如 safe-password-*）。
#   - [number]      约束 = `positive`（正整数）或 `min..max`（闭区间）。
#   - [requires]    约束写成 `触发 | 要求` 跨属性生效条件：
#       触发 `attr=*` 表示属性存在且取值非空（无值属性也触发）；`attr=v` 精确匹配；
#       `attr=!(a|b)` 表示取值不是其中任何一个。
#       要求 `attr=v` 要求该属性存在且等于 v；`attr=!(a|b)` 要求该属性不等于其中
#       任何一个，属性缺失时视为「不存在」：对 `!(...)` 视为满足，对 `=v` 视为不满足
#       （缺失即默认值，默认值通常正是被禁止的一侧）。
# 判定：只判静态属性（`{{}}` 插值跳过）；无值属性视为布尔 true，只有 `[unsupported]` 会报，
#   取值类约束（[enum]/[number]/[webview-only]）无法判定、跳过；值 trim 后大小写不敏感比较。
# 已知未覆盖：textarea 的 placeholder-class 同为 WebView-only，但知识库无 textarea
#   证据文件，按不确定不报处理。
